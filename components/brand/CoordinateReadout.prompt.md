A label/value list in IBM Plex Mono for machine facts — coordinates, datum, scale, accuracy, project counts.

```jsx
<CoordinateReadout
  label="Proyek aktif"
  items={[
    { label: 'Topografi Waduk Jatigede', value: '1:1.000' },
    { label: 'GNSS CORS Kab. Sleman', value: '±8 mm' },
    { label: 'Batas Desa Partisipatif', value: 'survei', emphasis: true },
  ]}
/>
```

Use it when the design should feel measured rather than marketed. Keep values short; long values break the two-column grid.
