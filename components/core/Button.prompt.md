The primary action — always pill-shaped, at every size.

```jsx
<Button iconLeft={<Icon name="user-plus" size={17} />}>Jadi anggota</Button>
<Button variant="secondary" iconLeft={<Icon name="calendar" size={17} />}>Agenda terdekat</Button>
<Button variant="accent" size="lg">Hubungi tim</Button>
<Button variant="on-dark" href="#">Lihat cara kerja</Button>
```

Hover on primary goes ink → green (not darker ink) — that colour shift is the brand's signature interaction. One primary per view; accent orange is for conversion moments only. Never square the corners.
