A single headline figure with its caption; used in stat bands and dashboard headers.

```jsx
<Stat value="1.204" label="Anggota aktif" />
<Stat value="±0,8 cm" label="Akurasi horizontal" mono />
<Stat value="48" label="Proyek selesai" tone="on-dark" size="lg" />
```

Marketing counts use Plex Sans; measurements (accuracies, areas, scales) use `mono`. Indonesian number format: dot as thousands separator, comma as decimal.
