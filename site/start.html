Cara pakai

Tiga cara memakai sistem ini, tergantung apa yang sedang kamu buat.

1 — Materi sekali pakai (slide, poster, feed IG)

Duplikat halaman contoh terdekat, lalu ganti isinya. Jangan mulai dari file kosong.

cp slides/two-column.html slides/rapat-februari.html
# lalu edit teksnya saja — struktur, warna, dan spacing sudah benar

Daftar lengkap halaman contoh ada di Template & kit.

2 — Halaman atau app baru

Cukup satu tautan stylesheet. Semua token, reset, font, dan kelas pola langsung tersedia.

<link rel="stylesheet" href="styles.css">

Untuk komponen React, muat bundel-nya lalu ambil dari namespace global:

<script src="_ds_bundle.js"></script>
<script>
  const { Button, Card, NavBar, EventCard } = window.BumiKalaChartaDesignSystem_5e0b40;
</script>

Nama namespace panjang karena dibuat otomatis. Simpan sekali di variabel (const BKC = window.BumiKalaChartaDesignSystem_5e0b40) daripada mengulangnya.

Pakai token, bukan angka

/* benar */
.panel{background:var(--surface-card);border-radius:var(--radius-card);
  padding:var(--space-6);box-shadow:var(--shadow-card)}

/* salah — nilai mentah tidak ikut berubah saat sistem diperbarui */
.panel{background:#fff;border-radius:20px;padding:24px}

3 — Project baru yang mengikuti sistem

Dua folder template siap dicopy. Masing-masing punya ds-base.js — satu baris di dalamnya menentukan lokasi design system-nya:

templates/slide-deck/          → SlideDeck.dc.html + ds-base.js
templates/instagram-carousel/  → InstagramCarousel.dc.html + ds-base.js

Copy foldernya, lalu sesuaikan const base di ds-base.js agar menunjuk ke lokasi design system relatif terhadap halaman itu.

Struktur folder

FolderIsi
styles.cssTitik masuk. Meng-import seluruh file token — ini satu-satunya file yang perlu ditautkan.
tokens/colors · typography · spacing · shape · fonts · base · patterns · contour-plates. Semua perubahan sistem dimulai di sini.
assets/Logo & maskot (PNG), 4 plate kontur (SVG), font IBM Plex (woff2).
components/23 komponen React, dikelompokkan: core · brand · navigation · forms · feedback · patterns.
guidelines/24 halaman spesimen — yang dirender di halaman Fondasi dan Brand.
slides/ · social/Halaman contoh siap-copy per layout (7 slide, 4 frame Instagram).
ui_kits/Dua kit layar penuh: website komunitas dan dashboard peta.
templates/Folder starter untuk project baru.
site/Situs dokumentasi ini.
readme.mdDokumentasi teknis lengkap — rujukan utama untuk developer dan AI.

_ds_bundle.js, _ds_manifest.json, _adherence.oxlintrc.json, dan support.js dibuat otomatis. Jangan diedit tangan — akan tertimpa. Setelah mengubah komponen atau UI kit, jalankan npm run build untuk membuat ulang _ds_bundle.js.

Aturan kontribusi

  • Token dulu. Warna, ukuran, atau spacing baru masuk ke tokens/ lebih dahulu, baru dipakai.
  • Satu nilai satu tempat. Kalau sebuah angka muncul di tiga halaman, jadikan token. Kalau hanya di satu halaman, jangan.
  • Komponen baru butuh tiga file: Nama.jsx, Nama.d.ts, dan satu spesimen di kartu grup terkait.
  • Plate kontur di-generate, bukan digambar. Jangan mengedit SVG-nya; regenerate supaya geometrinya tetap isoline yang benar.
  • Jangan menambah warna di luar palet. Kalau butuh nuansa baru, ambil dari skala hijau/oranye/netral yang sudah ada.

Menaruh di GitHub

Seluruh isi project ini bisa langsung di-push sebagai repositori statis. Untuk membuka situs dokumentasi ini lewat GitHub Pages, aktifkan Pages dari branch utama — index.html di root sudah mengarahkan ke site/index.html.

git init
git add .
git commit -m "BKC Design System v1.0"
git remote add origin git@github.com:<org>/bkc-design-system.git
git push -u origin main
